# 实现说明

## 游戏与玩家视图

`src/core/games/` 中的规则模块使用可序列化状态，负责初始化、校验并应用指令，以及生成玩家视图。非法指令不能部分修改状态。测试覆盖筹码与卡牌守恒、流程推进、胜负结算和隐藏信息。

云端模式由 Worker 持有完整状态，只发送对应玩家的视图；牌堆、他人手牌和秘密身份不能依靠前端隐藏。局域网模式由房主持有完整状态，经 WebRTC 向各玩家分发过滤后的视图，因此房主设备属于信任边界。房间码本身不是身份凭据：玩家通过房间凭据恢复身份，通过邀请链接或房主批准加入。

## 连接与恢复

- **云端**：WebSocket 连接 Durable Object，由 `GameRoom` 校验操作并保存房间状态。
- **局域网**：Worker 提供发现和信令，玩家通过 WebRTC DataChannel 连接房主；未配置 STUN / TURN。房主状态以 localStorage 持久保存并兼容旧 sessionStorage；关闭标签页后可恢复未过期且 matchID 匹配的牌局。
- **房间发现**：根据公开网络地址的服务器端散列分组，不扫描 Wi-Fi 名称，也不保证同一热点上的所有设备都能直连。
- **离线试玩**：Service Worker 缓存前端和素材；同屏轮换座位运行规则，不提供离线跨设备配对。

房间有过期清理机制。断线恢复与退出行为的修改应同时检查 `src/net/`、`worker/` 和 `tests/network/`。

## 本地数据

`mocha-profile` 保存昵称与头像；`mocha-room-session` 保存恢复房间的凭据及有效期；`mocha-host-*` 保存局域网房主状态（含秘密牌局，仅受信任房主可用）；`mocha-practice-v1` 保存同屏试玩。`mocha-history-v1` 仅保存本人已接收的结束结果摘要，不保存他人隐藏手牌，按持久 matchID 去重。删除战绩保留去重 ID，避免刷新终局重新写回。因离线未接收到的结束结果无法事后同步。

头像/战绩等存储不跨域或跨设备同步。存储失败会显示提示；清空浏览器数据会移除恢复能力。
