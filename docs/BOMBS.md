# 拆弹猫

`BombsEngine` 是纯 Swift、主机权威的 2–5 人规则引擎。中文牌名、说明和猫咪类别自行编写；没有打包商业游戏的插画或牌面素材。

规则依据：[Original Edition 官方规则入口](https://www.explodingkittens.com/pages/rules-kittens)、[2025 英文规则 PDF](https://cdn.shopify.com/s/files/1/0345/9180/1483/files/ekoe-instructions-english.pdf?v=1743802429)、[官方 Comprehensive Field Guide](https://www.explodingkittens.com/pages/comprehensive-field-guide)。核对日期：2026-09-19。

## 规则范围

- 每人初始 1 张拆弹、7 张无炸弹普通牌；牌堆加入人数减一张炸弹、最多 2 张额外拆弹。不启用可选快速局。
- 基础牌组包含攻击、跳过、索取、洗牌、预见未来、否决，以及 5 种各 4 张的猫牌。
- 攻击叠加保留当前及剩余攻击回合，再加 2；跳过、抽牌和成功拆弹各消耗一个回合。
- 抽到炸弹时可拆弹或放弃出局；拆弹后由本人秘密选择任意插入位置，包括顶部和底部。
- 索取由目标自行选牌；任意同名对子随机拿取；任意同名三张指定牌名，目标没有则无所得。
- 预见未来只显示给使用者；洗牌重新随机化；最后一名存活者获胜。
- 没有实现扩展包或旧版的五种异名牌组合（所采用最新基础规则不包含此组合）。

## 手机交互约定

所有可否决效果进入全员响应屏障：每位存活玩家都必须明确点击“不否决”，即使没有否决牌。这样不会从自动跳过推断谁没有否决牌。否决/反否决清空所有确认，重新等待全员响应。不依赖网络时延或倒计时。已确认的玩家仍可在最后一人确认前打出否决。玩家暂时断线会等待其重连，不自动代打。

出牌需要指定目标时分阶段选择；三张组合再选择牌名。取消只在效果提交前允许，不消耗牌。响应屏障结束后才实际拿牌、洗牌或展示未来，因此没有否决已经被提前揭晓的信息的问题。

## 隐私与验证

仅将 `view(for: peerPlayerID)` 发给对应玩家；引擎、种子、完整牌堆和其他投影不能发送。其他玩家只看手牌数量，死亡手牌保留暗置。所有牌的随机 ID 与牌型无关；未来视图使用位置 ID，避免曝光牌堆实体 ID。日志不写随机抽到/交出牌的内容或炸弹插入位置。

`apply` 使用副本验证并提交，错误不改变引擎或随机数状态。引擎只接受该玩家当前投影列出的行动及合法选项。

执行验证：

```sh
swift test --filter BombsTests
```

测试覆盖各人数安全开局、叠加攻击与单回合跳过、否决/反否决屏障、目标自主给牌、私密未来和插入位置、组合命中/失败/被否决、洗牌守恒、非法命令原子性，以及 120 局由投影行动驱动的完整随机对局（覆盖全部 14 种命令，每局持续检查炸弹数与存活人数关系、选项 ID 唯一性和选择数量约束）。
