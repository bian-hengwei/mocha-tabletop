# 社交推理规则与隐私

这两个纯 Swift 引擎不需要主持人。房主也只通过自己的 `view(for:)` 玩游戏。引擎保存在房主进程，应用没有查看全员身份的入口；这不是对恶意修改房主程序的密码学保护。网络必须只发送接收者自己的 GameView，不能序列化引擎或广播其他人的视图。身份和行动不是可持久化公开日志。

## 阿瓦隆

5–10 人；邪恶人数分别为 2 / 2 / 3 / 3 / 3 / 4。固定带梅林、派西维尔、莫甘娜、刺客，其余忠臣/爪牙。梅林看所有邪恶；邪恶互认；派西维尔看到梅林与莫甘娜的无序二人组。不加入莫德雷德、奥伯伦、湖中仙女扩展。

任务人数：5 人 [2,3,2,3,3]；6 人 [2,3,4,3,4]；7 人 [2,3,3,4,4]；8–10 人 [3,4,4,5,5]。队长每轮顺时针轮换。组队赞成必须严格超过半数，平票否决。连续五次否决立即邪恶获胜，通过组队后否决计数清零。

任务只能由队员秘密提交；好人只能成功，坏人可成功或失败。7 人以上的第 4 次任务至少两张失败才失败，其余一张即可。任务提交不显示进度，不公布某人出哪张牌；结算只公布失败牌总数。三个失败邪恶获胜；三个成功后刺客从好人中选择梅林，刺中邪恶获胜，否则好人获胜。投票全部提交后才公开每个人的赞成/反对。

参考原版出版规则：[The Resistance: Avalon rulebook](https://avalon.fun/pdfs/rules.pdf)，[出版商产品页](https://indieboardsandcards.com/our-games/the-resistance-avalon/)。

## 狼人杀：12 人预女猎守

4 狼人、4 平民、预言家、女巫、猎人、守卫。好人消灭全部狼人获胜；狼人杀光全部平民或全部神职（屠边）获胜。此处固定以下常见桌规，国内规则存在版本差异。

- 先进行第一夜，再在公布死讯前竞选警长。全员秘密选择上警，全部提交后公开候选；唯一候选自动当选。多人候选发言，候选可退水，全员确认讨论结束后，未参选者投票。全员上警且无人退水则无警长。最多票当选；平票候选 PK 后复投，仍平票则无警长。复投仅排除仍在竞选的候选人。选举结束后统一公布昨夜死亡，昨夜死亡者仍可竞选、投票；当选者若死亡立即移交警徽。警长放逐票 1.5 票；出局后可移交给存活玩家或撕毁警徽。
- 狼可在警上发言、白天讨论、平票 PK 发言时自爆，公开身份并结束白天；投票、猎人技能和警徽移交等结算期不可插入自爆。警上首次自爆保留其余候选到次日继续竞选；第二次警上自爆吞警徽。两次警上自爆都会正常结算昨夜死亡、合法猎人技能，再进入下一夜。持警徽的狼自爆也可以移交或撕毁警徽，完成后进入下一夜。
- 夜间对外永远只显示「第 N 夜 · 请闭眼」，不显示哪个身份正在行动、进度或玩家响应状态。所有存活玩家都要完成两轮个人操作，普通身份每轮确认闭眼。即便女巫已死，第二轮仍照常进行，避免通过阶段判断角色是否存活。
- 第一轮狼人选择刀口，必须所有存活狼人一致，否则空刀。已提交刀口仅狼队能看见，便于其他狼人跟随决定；提交后不可修改。允许空刀、自刀。不提供狼队私聊。预言家查一名其他存活玩家，结果只自己可见。守卫可空守、自守，但不能连续两夜守同一人；空守中断连续限制。
- 第二轮女巫用一瓶药或不用药。解药和毒药各一瓶且永久消耗；不能同夜双药、不能自救、不能自毒。尚持有解药时才能看到刀口；解药用完以后刀口不再告知。刀口信息是狼人原始选择，不显示是否被守护。被刀女巫仍能使用毒药。
- 守护抵挡狼刀，不能抵挡毒。守救同死：同一人同时被守护且被解药救起会死亡。毒杀无视守护和解药。死讯一次性公开，不说明死亡原因，不翻身份。
- 被刀或被放逐的猎人可开枪或放弃；被毒猎人不能开枪。猎人被刀又被毒时也不能开枪。合法猎人技能完成后再判断胜负。猎人发动时其身份通过公开技能显露。
- 白天现场发言，所有存活玩家确认后开始秘密放逐票；全员提交后统一公布。可弃票、可自投；首轮平票只允许票选 PK 候选，PK 发言后全体存活玩家复投，仍平票或全弃票则无人出局。没有倒计时，发言顺序由同桌玩家商议。
- 当前没有警长指定发言方向、遗言计时和扩展角色；不自动踢掉未操作玩家。断线时房间应等待恢复或由房主结束整局，不能用公开「正在等某身份」跳过。

## 验证

SocialTests 覆盖 80 局阿瓦隆与 60 局狼人杀的投影驱动随机完整对局，并逐步验证夜间公共投影保密。定向测试覆盖人数与身份构成、秘密投票屏障、非法命令原子拒绝、五次否决、三次任务与刺杀、七人第四任务两败门槛、守救同死、毒猎不开枪、猎人与警徽交接、首夜死讯延迟公布、退水、PK、守卫不能连守、双爆吞警徽、狼警长自爆的串行结算和投票期禁止自爆。所有选择依据当前私有 ActionPrompt 校验，拒绝后不得改变任何人的 GameView。
