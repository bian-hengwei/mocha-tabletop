# Mocha 桌游 · 验收记录

## 自动检查

`npm run check` 通过：132 项测试、前端 TypeScript、Worker TypeScript 与生产构建。覆盖四款游戏规则、玩家隐私投影、非法操作、联网去重、狼人杀法官及只发身份模式，并包含旧本机数据迁移测试。

## 游戏与界面验收

改版已通过 Chromium 和 WebKit 浏览器测试：

- 宝石商人：90 张牌、10 位贵族，直接点选筹码，支付、弃筹码、公开预留及盲抽预留，库存中的实际卡牌与各色统计。只能预留市场明牌或牌堆顶牌，最多三张；不能挑选任意暗牌或其他人的牌。
- 炸弹猫：多场完整对局、应对/Nope、连击、抽牌与秘密放回等阶段，多个 iPhone 横屏尺寸。
- 狼人杀：玩家操作；房主担任法官、其余玩家只看自己身份；全员只发身份、线下主持。覆盖人数上限、秘密投影和模式切换。
- 阿瓦隆：组队、同时投票、秘密任务牌、三次任务与刺杀。身份画像、队伍与投票状态均在页面验证。
- 安装入口：横屏首页和竖屏提示均有按钮。iPhone 展示 Safari 分享菜单的真实添加步骤；支持安装事件的浏览器可触发安装。
- LAN：Chromium/WebKit 的真实 WebRTC 对局、断线恢复、房主快照与切换云端测试。配对完成后断开信令仍可传输游戏操作。

正式站点： https://mocha-tabletop.bianhengwei.com 。Mocha 发布后的 Chromium 验收包含六种多人房间、刷新恢复、完整离线加载和四款同屏试玩；WebKit 验证六种多人房间、安装面板与新图标。

最终发布逐项对比 HTML、JavaScript、CSS、service worker、清单、图标与美术，共 19 个文件。部署版本与 SHA-256 校验见 `deployment-verification.json`。

## 范围说明

测试在隔离浏览器上下文运行，不等于物理 iPhone、真实路由器隔离、热点或锁屏后台验收。Chromium 完整离线加载及四款同屏试玩已验证；WebKit 验证在线交互与缓存，未声称其自动化离线导航通过。

Wi-Fi 模式仍需 Cloudflare 完成初始配对，没有 TURN 中继。附近房间是相同公网出口的候选结果，进入需要邀请或房主同意。不能直连时可切换云端。应用不承诺手机后台持续联网。
